# Changelog

## 0.3.1 — 2026-10-11

- Added a documentation index and source quickstart, a complete estimator-family
  overview, version-specific release downloads and manuscript/provenance links.
- Documented the distinction between current `main` documentation and the
  historical v0.3.0 snapshot, retaining its commit and tag verification links.
- Added a root-level methods PDF copied from the manuscript render, included in
  the provenance manifest, with validation that rejects missing or differing copies.
- Refreshed the manuscript renderer outputs while retaining the scientific
  producer snapshots and their recorded provenance.
- Prepared versioned citation metadata and the eight-asset archival bundle for
  DOI 10.5281/zenodo.23306201, including an exact-commit source ZIP. Publication
  and verification status are recorded in the [v0.3.1 release entry](docs/releases.md#v031).

## 0.3.0

- Added whole-observation exact and Monte Carlo permutation tests, paired and
  independent percentile bootstrap intervals, Wilson score intervals and
  fixed-family Holm adjustment, with explicit assumptions, seeds and work limits.
- Added fixed-alphabet symbolization with configured cuts, equality direction,
  retained empty categories and both amplitude tails.
- Moved runnable example controls into strict YAML plans and shared typed helpers;
  added an example of replicate inference alongside geometry, alphabet and cost
  examples.
- Added a prospective synthetic power study with independent whole-field pools,
  stochastic null controls, configured contrasts and sample-size grids, explicit
  unavailable decisions, uncertainty intervals and numerical replay controls.
- Extended the sourced manuscript and artifact validation to inference and power
  outputs. These demonstrations do not establish biological sample sizes or
  reproduce the source paper's empirical results.

See the [release guide](docs/releases.md) for version history, downloads,
checksum verification and installation from the release wheel.

## 0.2.0

- Replaced the custom manuscript renderer with the authenticated, pinned
  docxology/template pipeline: configurable ordered sections, sourced variables,
  native equations, bibliography, bookmarks and a real table of contents.
- Added replicated native-dimensional MIX and structured controls, explicit
  flattening comparisons, fixed-alphabet complexity, outcome-aware summaries and
  complementary figures, with numerical replay and completeness controls.
- Added planning for nine observation estimators, exact blocked work counts,
  conservative memory guards, real kernel benchmarks and executable examples.
- Corrected weighted Jensen-Shannon precision near equal distributions and at
  extreme weights, with independent high-precision numerical oracles.
- Expanded validation for typed trial identities, duplicate columns, nonfinite
  outcomes, producer plans, renderer provenance and the displayed manuscript values.

## 0.1.0

- Added dimension-agnostic HDSE and related local-template estimators with explicit
  geometry, tolerance, exclusions, degeneracy and resource limits.
- Added probability information, spatial ordinal, full FFT and SVD measures.
- Added typed results, validated batches, safe numeric file CLI, deterministic
  synthetic experiments, hashed artifacts and an inspectable methods manuscript.
- Established numerical, adversarial, packaging, type, lint and coverage checks.

This entry describes the initial implementation; no PyPI or DOI release is claimed.

# Changelog

## 0.1.0

- Added dimension-agnostic HDSE and related local-template estimators with explicit
  geometry, tolerance, exclusions, degeneracy and resource limits.
- Added probability information, spatial ordinal, full FFT and SVD measures.
- Added typed results, validated batches, safe numeric file CLI, deterministic
  synthetic experiments, hashed artifacts and an inspectable methods manuscript.
- Established numerical, adversarial, packaging, type, lint and coverage checks.

This entry describes the initial implementation; no PyPI or DOI release is claimed.

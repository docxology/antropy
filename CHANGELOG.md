# Changelog

## 0.2.0

- Replaced the custom manuscript renderer with the authenticated, pinned
  docxology/template pipeline: configurable ordered sections, sourced variables,
  native equations, bibliography, bookmarks and a real table of contents.
- Added replicated native-dimensional MIX and structured controls, explicit
  flattening comparisons, fixed-alphabet complexity, outcome-aware summaries and
  complementary figures, with numerical replay and completeness controls.
- Added planning for nine observation estimators, exact blocked work counts,
  conservative memory guards, real kernel benchmarks and executable examples.
- Corrected weighted Jensen-Shannon precision near equal distributions and at
  extreme weights, with independent high-precision numerical oracles.
- Expanded validation for typed trial identities, duplicate columns, nonfinite
  outcomes, producer plans, renderer provenance and the displayed manuscript values.

## 0.1.0

- Added dimension-agnostic HDSE and related local-template estimators with explicit
  geometry, tolerance, exclusions, degeneracy and resource limits.
- Added probability information, spatial ordinal, full FFT and SVD measures.
- Added typed results, validated batches, safe numeric file CLI, deterministic
  synthetic experiments, hashed artifacts and an inspectable methods manuscript.
- Established numerical, adversarial, packaging, type, lint and coverage checks.

This entry describes the initial implementation; no PyPI or DOI release is claimed.

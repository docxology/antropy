# Template adaptation record

Source template: [docxology/template_code_project](https://github.com/docxology/template_code_project).
Observed source HEAD: `04040a1e8eda0b31ce61db888cd1b3598f1696ca` on 2026-10-09.
This is the attribution for the project scaffold, not an antropy release DOI.

Retained patterns are separation of numerical source, tests, research scripts,
input data, manuscript source and generated outputs; a validated experiment plan;
reproducible result/figure production; contribution guidance; citation metadata;
and explicit quality gates. The template's optimization demonstration, imported
scientific claims, monorepo paths, release receipts and published DOI metadata
were not reused as antropy evidence.

The initial adaptations were a standalone `antropy-hd` wheel; the `antropy_hd` namespace;
dimension-aware local geometry; a strict result/configuration schema; focused
synthetic entropy experiments; independent installed-wheel checks; an inspectable
Markdown manuscript; and a small standalone PDF renderer. That renderer has now
been replaced by the actual canonical template infrastructure.

The manuscript dependency is the public `research-project-template[rendering]`
distribution from [docxology/template](https://github.com/docxology/template),
pinned at `d39f2478da2512b42ad961e98a5f3b854723f92e`. The exemplar is
`projects/templates/template_code_project/manuscript`. The adapter invokes its
real strict variable substitution and ordered Pandoc/LaTeX rendering APIs; it does
not vendor a replacement renderer. Package VCS metadata and installed RECORD
hashes authenticate the provider, and the output receipt records tool versions,
section order, source/variable/figure hashes, TeX, TOC and PDF identities.

Project-specific metadata, author settings, bibliography, producer requirements
and rendering options are explicitly configured. Optimization results, borrowed
DOIs, journal identities, confidentiality watermarks and publishing credentials
are not inherited from the exemplar. Configured variables derive from consumed
plans and measured outputs. Native mathematical typesetting, cross-references,
section bookmarks and the table of contents are generated by the template route.

Manuscript dependencies remain development-only: installing the numerical wheel
does not install the template, plotting stack or system TeX tools. The external
template checkouts were inspected read-only and their unrelated work preserved.

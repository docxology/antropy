# Template adaptation record

Source template: [docxology/template_code_project](https://github.com/docxology/template_code_project).
Observed source HEAD: `04040a1e8eda0b31ce61db888cd1b3598f1696ca` on 2026-10-09.
This is the attribution for the project scaffold, not an antropy release DOI.

Retained patterns are separation of numerical source, tests, research scripts,
input data, manuscript source and generated outputs; a validated experiment plan;
reproducible result/figure production; contribution guidance; citation metadata;
and explicit quality gates. The template's optimization demonstration, imported
scientific claims, monorepo paths, release receipts and published DOI metadata
were not reused as antropy evidence.

The initial adaptations were a standalone `antropy-hd` wheel; the `antropy_hd` namespace;
dimension-aware local geometry; a strict result/configuration schema; focused
synthetic entropy experiments; independent installed-wheel checks; an inspectable
Markdown manuscript; and a small standalone PDF renderer. That renderer has now
been replaced by the actual canonical template infrastructure.

The manuscript dependency is the public `research-project-template[rendering]`
distribution from [docxology/template](https://github.com/docxology/template),
pinned at `d39f2478da2512b42ad961e98a5f3b854723f92e`. The exemplar is
`projects/templates/template_code_project/manuscript`. The adapter invokes its
real strict variable substitution and ordered Pandoc/LaTeX rendering APIs; it does
not vendor a replacement renderer. Package VCS metadata and installed RECORD
hashes authenticate the provider, and the output receipt records tool versions,
section order, source/variable/figure hashes, TeX, TOC and PDF identities.

Project-specific metadata, author settings, bibliography, producer requirements
and rendering options are explicitly configured. Optimization results, borrowed
DOIs, journal identities, confidentiality watermarks and publishing credentials
are not inherited from the exemplar. Configured variables derive from consumed
plans and measured outputs. Native mathematical typesetting, cross-references,
section bookmarks and the table of contents are generated by the template route.

Manuscript dependencies remain development-only: installing the numerical wheel
does not install the template, plotting stack or system TeX tools. The external
template checkouts were inspected read-only and their unrelated work preserved.

## Replay the PDF from the checked-in results

The native builder retains its installed Template dependency and release
provenance contract. The standalone replay uses
[Template at commit `87704feae0a4490ef7dad9c931d268e8c30273c2`](https://github.com/docxology/template/tree/87704feae0a4490ef7dad9c931d268e8c30273c2)
to verify the canonical source and configured PDF using the committed
synthetic experiment values and exact figure files. It excludes archived TeX outputs from the source discovery pass. Run the replay in a
disposable checkout because it writes generated copies under `output/`.

At the pinned Template checkout, provision `uv sync --locked` and put compatible
Pandoc, pandoc-crossref, XeLaTeX and BibTeX on `PATH`. Place a clean antropy
checkout at `projects/working/antropy`. From the Template root:

```bash
uv run --no-sync python - <<'PY'
import json
import re
from pathlib import Path
from shutil import copyfile

import yaml
from infrastructure.rendering.manuscript_injection import (
    substitute_manuscript_text,
    write_resolved_manuscript_tree,
)

project = Path("projects/working/antropy").resolve(strict=True)
source = project / "docs/manuscript"
profile = yaml.safe_load((source / "project.yaml").read_text())
config = yaml.safe_load((source / "config.yaml").read_text())
sections = config["front_matter"]["files"]
if sections != profile["sections"]:
    raise SystemExit("Mismatch between native and replay section order")
variables = json.loads((project / "output/data/manuscript_variables.json").read_text())
for name in sections:
    _, missing = substitute_manuscript_text((source / name).read_text(), variables)
    if missing:
        raise SystemExit(f"{name}: missing snapshot values for {sorted(set(missing))}")
resolved = write_resolved_manuscript_tree(project, variables)
# The archived native .tex is a compiler receipt. The source for this run is Markdown.
for path in resolved.glob("*.tex"):
    path.unlink()

figures = project / "output/figures"
output = project / "output"
image = re.compile(r"!\[([^\]\n]+)\]\(([^)\s]+)\)\s*\{#(fig:[\w.:-]+)")
registry = {}
for name in sections:
    section = resolved / name
    for caption, target, label in image.findall(section.read_text()):
        reference = (section.parent / target).resolve(strict=True)
        reference.relative_to(output)
        destination = figures / reference.name
        if destination.exists() and destination.read_bytes() != reference.read_bytes():
            raise SystemExit(f"Conflicting figure basename: {reference.name}")
        if not destination.exists():
            copyfile(reference, destination)
        registry[label] = {"filename": destination.name, "alt_text": caption}
(figures / "figure_registry.json").write_text(
    json.dumps(registry, indent=2, sort_keys=True) + "\n"
)
PY
uv run --no-sync python scripts/pipeline/stage_03_render.py --project working/antropy --skip-manuscript-hydration
uv run --no-sync python scripts/pipeline/stage_04_validate.py --project working/antropy
```

Inspect `projects/working/antropy/output/pdf/antropy_combined.pdf` and the
validation reports under `output/reports/`. The repository's
`antropy-methods.pdf` and `output/provenance/` record the native publication
build. Use a separate worktree for native regeneration and verification.
